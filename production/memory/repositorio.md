# El código del rediseño vive en el repo público GitHub MrFobia/la-cometa-rediseno
<!-- backbone:type:reference -->
Source: user-stated

El `origin` del repo del proyecto apunta a `https://github.com/MrFobia/la-cometa-rediseno.git`
(público, rama `main`). Ahí está el rediseño completo de galerialacometa.com: las vistas
`.blade.php`, los assets, la fuente HTML y el sistema de tokens. El repo local vive en
`/var/www/html/storage/app/projects/re-diseno-la-cometa/` (la raíz git es el directorio del
proyecto, NO `production/`). El 2026-09-10 se trajo todo el contenido a local con un merge de
historias no relacionadas.
